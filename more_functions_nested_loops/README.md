# Low-Level Programming - More Functions and Nested Loops

This repository contains C programming tasks focused on learning control structures, loops, and building custom functions without standard library dependencies.
* **1-isdigit.c**: A function that checks for a digit (`0` through `9`). Returns `1` if it is a digit, and `0` otherwise.
* **2-mul.c**: A function that multiplies two integers and returns the result.
* **3-print_numbers.c**: A function that prints the numbers from `0` to `9`, followed by a new line, using `_putchar`.
* **4-print_most_numbers.c**: A function that prints the numbers from `0` to `9`, skipping `2` and `4`, followed by a new line.
* **5-more_numbers.c**: A function that prints 10 times the numbers from `0` to `14`, followed by a new line.
* **6-print_line.c**: A function that draws a straight line in the terminal based on the input length.
* **7-print_diagonal.c**: A function that draws a diagonal line on the terminal using nested loops.
* **8-print_square.c**: A function that prints a square on the terminal using the `#` character.
